# iliasa101.github.io

Личная страница с приложениями и инструментами: https://iliasa101.github.io/

Одна статическая страница без сборки и зависимостей: разметка, стили и скрипт —
в `index.html`, медиа — в `assets/`.

## Порядок на странице

1. **Шапка** на тёмном фоне: знак, имя, две строки о себе, контакты.
2. **Главный проект** — Sosnina Albums: запись экрана, описание, снимок рабочего окна.
3. **Инструменты** — finboard-anon, aiexport.
4. **Игры и развлечения** — Диплодок, Васюлятр, «Обмен наклейками» (с плашкой «Скоро»).

На карточках Диплодока и Васюлятра стоят сгенерированные обложки. Чтобы вернуть
настоящий игровой кадр и иконку приложения, достаточно поменять `src` у картинки
на `assets/diplodok.webp` или `assets/vasulyatr-icon.png` (иконке нужен ещё класс
`contain` у обёртки `.card-cover`).

Рецепт генерации и журнал опытов — `CommonKnowledge/wails-desktop/graphics-packs.md`
и `diplodok-kladoiskatel/docs/art-pipeline.md`. Коротко: чистый белый фон,
«grid of N columns and M rows» вместо «N×M», явные запреты `no text, no letters,
no numbers`, отбор годных глазами.

## Как менять

1. Открыть `index.html` в редакторе.
2. Карточка проекта — блок `<article class="card">` в нужной секции. Скопировать
   соседнюю и поправить: `.card-cover` — картинка (`contain` — если это иконка,
   а не обложка), `.tag` — тип и платформа, `<h3>` — название, первый `<p>` — что
   это, `<p class="aside">` — деталь или оговорка, `.stack` — стек, `.actions` —
   кнопка действия и ссылка на исходники.
3. Проверить локально — открыть файл в браузере двойным щелчком; если нужны
   относительные пути и видео, поднять сервер: `python -m http.server 8787`.
4. `git commit` и `git push` — GitHub Pages обновится за минуту-две.

Тёмная тема берётся из настроек системы (`prefers-color-scheme`), переключателя нет.
Карточки появляются при прокрутке и видео играет само — всё это выключается, если
в системе включено «уменьшить движение» (`prefers-reduced-motion`), и тогда у видео
появляются обычные кнопки управления.

## Публикация

Репозиторий пользовательский (`IliaSA101.github.io`), поэтому Pages отдаёт его по
корневому адресу. Источник — ветка `main`, папка `/` (Settings → Pages). Файл
`.nojekyll` отключает обработку Jekyll: страница отдаётся как есть.
