# iliasa101.github.io

Личная страница с приложениями и инструментами: https://iliasa101.github.io/

Одна статическая страница без сборки и зависимостей — весь сайт в `index.html`
(разметка, стили и иконки внутри одного файла).

## Как менять

1. Открыть `index.html` в редакторе.
2. Карточка проекта — блок `<article class="card">` внутри нужной секции
   («Приложения и игры» или «Инструменты»). Скопировать соседнюю и поправить:
   `.tag` — тип и платформа, `<h3>` — название, первый `<p>` — что это,
   `<p class="aside">` — деталь или оговорка, `.stack` — стек и свойства,
   `.actions` — кнопка действия (играть / скачать) и ссылка на исходники.
3. Проверить локально: открыть файл в браузере двойным щелчком.
4. `git commit` и `git push` — GitHub Pages обновится за минуту-две.

Тёмная тема берётся из настроек системы (`prefers-color-scheme`), отдельного
переключателя нет. Сетка карточек перестраивается сама от ширины экрана.

## Публикация

Репозиторий пользовательский (`IliaSA101.github.io`), поэтому Pages отдаёт его
по корневому адресу `https://iliasa101.github.io/`. Источник — ветка `main`,
папка `/` (Settings → Pages). Файл `.nojekyll` отключает обработку Jekyll:
страница отдаётся как есть.
